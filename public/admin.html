从金山文档导入回忆

三种方式任选：文件导入最稳（在金山文档里 文件 → 下载/导出 → Word(.docx) 或 纯文本(.txt)）； 粘贴文本适合少量内容；链接导入仅对公开无权限的分享链接可能生效。
把文件拖进来，或点击选择
支持 .docx / .txt / .md / .csv / .html，单文件最大 2.5GB
整份文档 = 一条回忆。段落、标题、表格顺序都保留，文档里的照片会一张张抽出来插在原位置 —— 适合「一个年级/一个班的回忆录」这种本来就写在一份 Word 里的东西。
把这份 .docx 拖进来，或点击选择
整篇保留照片只有 .docx 行；.txt / .md / .html 会当纯文本发一条
要求该链接的分享权限是「获得链接的人可查看」。若提示需要登录，请改用文件导入。
