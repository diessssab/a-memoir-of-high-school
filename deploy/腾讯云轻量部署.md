# 部署到腾讯云轻量应用服务器（图文步骤版）

> 面向「第一次上云」的情况写的：不用懂运维，照着敲就行。
> 项目里已经带了 `deploy/lighthouse-install.sh`（一键脚本）和 `deploy/nginx.conf`（反向代理配置）。

---

## 0. 先回答你最关心的问题：别人能在浏览器里打开吗？

**能。** 但要满足两个前提，缺一个就打不开：

| 前提 | 说明 | 不做的后果 |
| --- | --- | --- |
| **① 云服务器防火墙放行 80/443** | 腾讯云控制台 → 轻量应用服务器 → **防火墙** 里加规则 | 外网连不上，表现是「一直在转圈 / 无法访问」 |
| **② 域名做 ICP 备案**（用域名访问时） | 腾讯云控制台 → **网站备案**，免费，可代办 | 备案通过前，域名访问国内服务器会被拦，页面显示「该网站未备案」 |

几条容易被忽略的规则，按腾讯云当前政策（以官网为准）：

- **国内地域**（北京 / 上海 / 广州 / 成都…）：域名必须先备案。备案周期一般 **1～3 周**（管局审核最长 20 个工作日）。
  备案要求：域名已实名认证、服务器**购买时长通常 ≥ 3 个月**、网站负责人证件 + 人脸核验。
- **香港 / 新加坡地域**：**不需要备案**，买完配好域名立刻能用。代价是延迟高一些（华北用户大约 40～90ms），
  而且用不了国内 CDN、部分校园网/单位网可能访问不稳。
- **备案没下来之前怎么给同学用**：直接让他们访问 `http://服务器公网IP:3000`（控制台防火墙临时放行 3000 端口），
  功能完全一样，只是地址难看、没有 HTTPS。**备案通过后**再把地址换成域名，两个可以并存。

给廊坊的同学用，建议：**华北地域（北京/天津）+ 备案域名**，体验最好。

## 1. 买机器怎么选

| 项 | 建议 | 说明 |
| --- | --- | --- |
| 规格 | **2 核 2G 起**（2 核 4G 更稳） | 几百人/天、几十人同时在线完全够；JSON 存储不占内存 |
| 系统盘 | **80GB 起** | 照片是**按原尺寸**存的，一份大 Word 就能吃掉 0.5GB |
| 带宽 | 3～6 Mbps | 看文字、缩略图够用；翻看整篇几百张原图会慢，这是带宽限制不是代码问题 |
| 镜像 | **Ubuntu 22.04 LTS**（或 24.04） | 一键脚本按它是写的；也可以选宝塔镜像（见第 6 节） |
| 地域 | 北京 / 天津 | 离廊坊最近 |

> 不想备案、只想快点上线：选**香港地域**，跳过备案这步。

## 2. 五步装上去

### 第 1 步：放行防火墙

控制台 → 轻量应用服务器 → 点你的机器 → **防火墙** → 添加规则：

| 应用类型 | 协议 | 端口 |
| --- | --- | --- |
| HTTP | TCP | 80 |
| HTTPS | TCP | 443 |
| 自定义（仅测试期用） | TCP | 3000 |

### 第 2 步：把代码传上去

在**你自己电脑**上、项目**上一级目录**执行（Windows 10+ 自带 `tar` 和 `ssh`）：

```powershell
# 打包（排除依赖、缓存和本地测试数据）
tar --exclude=node_modules --exclude=.npm-cache --exclude=_shots --exclude=data -czf memoir.tar.gz langfang-memoir

# 上传
scp memoir.tar.gz root@你的公网IP:/opt/

# 解压
ssh root@你的公网IP "cd /opt && rm -rf langfang-memoir && tar xzf memoir.tar.gz"
```

> 也可以用 **VSCode 的 Remote-SSH** 插件连上服务器，直接在左侧文件树里右键上传；
> 或者把项目推到 GitHub/Gitee，在服务器上 `git clone`（长期维护更省事）。

### 第 3 步：跑一键脚本

```bash
ssh root@你的公网IP
cd /opt/langfang-memoir
sudo DOMAIN=memoir.example.com bash deploy/lighthouse-install.sh
```

- **还没有域名**就先别写 `DOMAIN`：`sudo bash deploy/lighthouse-install.sh`。
- 脚本会做：装 Node 20（走国内镜像）→ 建专用用户 `memoir`（不用 root 跑网站）→ `npm install` →
  生成 `.env`（**随机** `SESSION_SECRET` 和**随机后台密码**）→ 装 systemd 服务（开机自启、挂了自动拉起）→
  装 nginx 反向代理 80 → `127.0.0.1:3000`（并放开 2.5GB 上传、长超时）→ 自检。
- 装完屏幕上会打印**后台密码**，也会存一份在 `/opt/langfang-memoir/data/.admin-password`。
- 脚本可以重复跑：改完域名再跑一次只会更新 nginx/systemd 配置，不动 `data/` 和 `uploads/`。

### 第 4 步：域名解析 + 备案

1. 域名解析：DNS 添加 **A 记录** → `@` 和 `www` 都指向服务器公网 IP。
2. 备案：控制台 → 网站备案 → 按提示提交（选「腾讯云服务器」、填网站名称「廊坊一中回忆录」、
   网站内容选「其他 / 学校回忆录」类）。备案期间**不要**关服务器。
3. 备案通过后，确认 `http://你的域名` 能打开。若之前没带 `DOMAIN` 跑过脚本，补跑一次：

```bash
sudo DOMAIN=memoir.example.com bash deploy/lighthouse-install.sh
```

### 第 5 步：上 HTTPS（强烈建议）

**为什么必须做**：Chrome / Edge 只在「安全来源」上提示保存密码。走 `http://` 时「让浏览器记住密码」那个弹窗不会出现，
同学每次都得重新输。上了 HTTPS 才有。

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d memoir.example.com -d www.memoir.example.com
```

certbot 会自动改 nginx 配置并配好续期。然后把 `.env` 里的地址改成 https：

```bash
sed -i 's|^SITE_URL=.*|SITE_URL=https://memoir.example.com|' /opt/langfang-memoir/.env
systemctl restart langfang-memoir
```

## 3. 装完自己验收（6 条）

按顺序试，哪一步挂了就照「多半是」那列查：

| 试什么 | 应该看到 | 多半是 |
| --- | --- | --- |
| `http://公网IP:3000` | 登录页 | 防火墙没放行 3000，或服务没起（`systemctl status langfang-memoir`） |
| `http://公网IP`（80） | 同一个登录页 | nginx 没起 / 自带 default 站点没清（脚本会清 `/etc/nginx/sites-enabled/default`） |
| `http://域名` | 同上 | DNS 没生效（`ping 域名`看 IP）、或**备案没过** |
| 登录 → 关浏览器 → 再打开 | 账号还在 | 正常；但**不弹保存密码**是没上 HTTPS |
| 后台 `/admin` 登录 | 概览七个标签 | 密码在 `data/.admin-password`；连错 8 次会锁 15 分钟 |
| 后台导入一份大 Word | 进度条走、墙上出现「整篇文档」 | 413 = nginx `client_max_body_size` 不够；卡住 = 上传带宽/超时 |

## 4. 磁盘会怎么涨（**最重要的一节**）

- 一份 424MB 的 Word（225 张照片）导进来 → 照片 **443MB** 落在 `uploads/posts/<回忆id>/`，正文 HTML 同目录。
- 导入时原文件还会先在 `uploads/docs/` 临时占一份，**导入完自动删掉**，所以峰值需要 2 倍空间。
- **80GB 盘** ≈ 系统 5GB + 约 **130 份**大文档。到 70% 就该动手了。
- `data/db.json` 很小（KB 级，只存文字摘要），`npm run backup` 备份的就是它 —— **照片不在备份里**。
- 所以：**每周在控制台做一次「快照」**（轻量 → 快照，几毛钱/GB·月），这是唯一能救回照片的办法。
- 空间不够时：后台「监控中心 → 文件监控 → 删除」会连同照片目录一起删；或者升级系统盘（轻量支持在线扩容）。

## 5. 日常运维（三行命令）

```bash
systemctl status langfang-memoir      # 看是否在跑
journalctl -u langfang-memoir -f      # 实时日志（Ctrl+C 退出）
systemctl restart langfang-memoir     # 改完代码/配置重启
```

- 更新代码：本地改完按第 2 步重新打包上传（**不用**重跑安装脚本），然后 `systemctl restart langfang-memoir`。
- nginx 日志：`/var/log/nginx/access.log`、`error.log`（看谁在扫站点、哪个请求 413）。
- 加自动备份：`crontab -e` 加一行（每天 03:00，保留 14 份）：
  ```
  0 3 * * * cd /opt/langfang-memoir && /usr/bin/node scripts/backup.js --keep=14
  ```
- 想把数据库拉回本地看：`scp root@公网IP:/opt/langfang-memoir/backups/*.gz .`

## 6. 不想敲命令：用宝塔面板（图形界面）

轻量应用服务器可以直接选「**宝塔 Linux 面板**」镜像，装完拿到面板地址和账号，然后：

1. 软件商店装 **Node.js 版本管理器** → 装 v20；
2. 上传代码到 `/www/wwwroot/langfang-memoir`；
3. 终端里 `npm install --omit=dev`，或用宝塔「Node 项目」新建项目（启动文件 `server/index.js`、端口 3000）；
4. 网站 → 添加站点（绑域名）→ 设置 → **反向代理** → `http://127.0.0.1:3000`；
5. 反向代理配置里把 `client_max_body_size 2600m;`、`proxy_read_timeout 1800s;`、`proxy_request_buffering off;` 加上；
6. SSL → Let's Encrypt 一键申请。

宝塔更省心，但多一个常驻面板（建议改端口 + 开二次验证 + 限制 IP）。

## 7. 上线前安全清单

- [ ] `SESSION_SECRET` 是随机的（一键脚本已自动生成）
- [ ] 后台密码已改（脚本随机生成；后台「密码管控 → 站长后台密码」可改）
- [ ] `.env` 权限 600（脚本已设），别提交到 Git
- [ ] `SITE_URL` 填真实地址（https 后别忘了改）
- [ ] `TRUST_PROXY=1`（脚本已设，否则后台看到的全是 127.0.0.1）
- [ ] HTTPS 已开（浏览器才会提示保存密码）
- [ ] 每周快照 + 每日 db 备份
- [ ] 可选：后台只允许自己 IP 访问，在 `/etc/nginx/conf.d/memoir.conf` 里加

  ```nginx
  location ~ ^/(admin|monitor)(\.html)?$ {
      allow 1.2.3.4;      # 你的固定 IP
      deny all;
      proxy_pass http://memoir_app;
  }
  ```

  （注意：这只挡页面，接口 `/api/admin/*` 仍靠密码保护；所以密码一定要强。）

## 8. 常见问题

**Q：能同时给几百个同学用吗？**
能。这是单进程 Node + JSON 文件库，日常几十人同时在线没问题（瓶颈在带宽和磁盘，不在代码）。
真到几千人日活再考虑换 SQLite/Postgres 和多进程。

**Q：服务器重装系统会不会丢数据？**
会。`data/` 和 `uploads/` 都在系统盘上。所以：**换系统前先快照**，或定期把 `backups/` 拉回本地。

**Q：2.5GB 的文档传得上去吗？**
可以，但很慢：家里上行 10Mbps 传 2.5GB 要 35 分钟左右，中途**别关页面、别让电脑休眠**。
更省事的做法：在自己电脑上把 Word 拆成几份（按年级/按班级），一份一份导。

**Q：域名能随便用吗？**
不能。`.com/.cn/.top` 都行，但要**实名认证**，且备案时域名后缀必须在工信部允许列表内（`.xyz`、部分小众后缀不能备案）。
