# 廊坊一中回忆录

*An open-source template for a high-school memoir site —— 校友回忆墙 + 站长后台，clone 下来改成自己学校就能用。*

给校友们用的小站：用「几几级 + 班 + 姓名」登记进来，在回忆墙上写当年的故事，评论、点赞、传照片。
站长有一个独立的后台，能看到谁在什么时候访问了什么页面，能封禁捣乱的人、隐藏或删除内容。

- 后端：Node.js + Express，数据存在一个 JSON 文件里（不用装数据库）
- 前端：原生 HTML/CSS/JS，没有构建步骤，改完刷新就看到
- 无需联网服务、无需购买第三方组件，`npm install && npm start` 就能跑

> **关于隐私：这个仓库只有代码。**
> `data/`（数据库、后台密码、会话密钥）和 `uploads/`（校友传的文档、照片）都在 `.gitignore` 里，
> 不会进 Git，也不会公开。你 clone 下来第一次启动时，程序会自动建一个空库、自动生成一个新的后台密码，
> 不需要任何示例数据；想造点测试内容，就在前台用「1995级 3班 张三」这种假名字登记几次。
>
> 许可证见 [LICENSE](LICENSE)（MIT）。换成自己学校的名字以后，建议把本文件里的「廊坊一中」一并替换。

## 一、在 VSCode 里跑起来

需要 Node.js **18.17 以上**（推荐 20 / 22 LTS）。打开终端：

```bash
cd langfang-memoir
npm install
npm start
```

看到这样的横幅就成功了：

```
────────────────────────────────────────────
  廊坊一中回忆录  已启动
  本地访问   http://localhost:3000
  后台入口   http://localhost:3000/admin
  后台密码   x7Kp2q          ← 首次运行自动生成
────────────────────────────────────────────
```

- 前台：<http://localhost:3000>
- 后台：<http://localhost:3000/admin>（密码就是横幅里那串）
- 开发时想改了代码自动重启：`npm run dev`

> 后台密码自动保存在 `data/.admin-password`，可在 `.env` 里用 `ADMIN_PASSWORD` 自己指定。
> 想换密码：删掉 `data/.admin-password` 再重启，或用 `.env` 指定。

## 三、站内是怎么运作的

### 1. 登记 / 登录

首页右边那张卡片上有两个页签，共用**同一个输入框**：

| 字段 | 说明 |
| --- | --- |
| 你是谁 | 一句话写清「几几级的谁谁谁」，例如 `1998级3班 张三`、`95级 李四`、`2001级2班 王五`。班级可省；省略后有重名会提示你补上班级 |
| 密码 | 自己定，默认**只要求 1 位**（站长可在后台调高到 6/8 位……） |
| 再输一遍 | 只有「第一次来 · 登记」页有 |

- **第一次来** → 点「登记」页签，设一个自己的密码；
- **老同学** → 点「登录」页签，同样的写法 + 密码；
- 同一个「级别 + 班级 + 姓名」再登进来，还是同一个人，不会重复建号；
- 登录后右上角会出现「账号」，进去可以自己改密码（改完其它设备会掉线）。

**浏览器会记住它。** 登录用的是浏览器原生表单（不是前端拼的 fetch），输入框都带
`autocomplete="username"` / `current-password` / `new-password`，所以 Chrome、Edge、Safari、
Firefox、手机系统浏览器在第一次登录后都会弹「是否保存密码」，选「保存」——
下次点一下输入框就自动填好「1998级3班 张三」+ 密码，不用再记。
如果没弹，检查浏览器设置里「自动填充 → 密码」是否开着，且访问地址不是无痕窗口。

**忘记密码了怎么办？** 登录页底部有「忘记密码 / 有事找站长」的入口，点开会展开
你在后台填的微信 / QQ / 邮箱 / 电话，一键复制发给站长。站长收到后到后台「密码管控」里
点一下「重置」，会生成一串临时密码（只显示一次），你用它在登录时会直接被要求改成自己的新密码。

### 2. 回忆墙

- 按届别筛选、搜索关键词、按最新或最热排序、只看自己写的
- 每张便签可以点赞（同一人再点取消）、点开看全文和评论
- 允许传图片（jpg/png/gif/webp，单张 8MB，每条最多 6 张）

### 3. 传文档（在「写回忆」弹窗里，校友自己传）

在回忆墙点「写一条回忆」，弹窗里除了写文字，还能**直接传一份文档**：

- 支持 `.docx` / `.txt` / `.md` / `.csv` / `.html`，**单份最大 500MB**（`MAX_UPLOAD_MB` 可调）。
  上传走磁盘流，不占内存；文本逐行流式解析，几百 MB 的 txt 也是边读边切、读够就停。
- **`.docx` 走「整篇模式」**：整份文档变成**一条**回忆，标题、加粗、下划线、表格都保留，
  **照片留在它们原来的位置**（实测一份 424MB、225 张照片的年级回忆录，转换 3.8 秒）。
  传完显示「会作为一整篇发到回忆墙上（共 225 张照片）」，点「发布这一篇」就上墙。
  转换在**上传时**就做完，所以点发布是秒响应；原 `.docx` 转换完立刻删掉（照片已经解压出来了）。
- `.txt` / `.md` / `.csv` / `.html` 仍按署名拆成多条：署名行（`1995级3班 张三`）后面跟的正文算一条，
  或用 CSV/制表符表格（表头含「姓名 / 内容」）。切不开会提示。
- 传完都会先给人看一眼再发布——**不需要站长审核**，校友点一下就直接出现在回忆墙里。
- 传了文档但没点发布（关了弹窗），下次打开「写回忆」时会提示「上次那份还没发出去」，可以接着发或删掉。
  整篇模式那类超过 7 天还没发布的，服务端会顺手清掉，免得几百 MB 的照片一直占磁盘。

站长那边在 **监控中心 → 文件监控** 里能看到每一份上传（谁传的、IP、大小、是不是整篇、几张照片、有没有敏感词），
点开能看**正文（整篇模式看的是全文）**，觉得不合适就点「删除」——记录、照片目录和从这份文档发上墙的回忆会一起删掉。
单个帖子、评论的删除在后台「内容管理」里。

### 4. 后台（只有站长能进）

`/admin` 输密码，进去后八个标签：

| 标签 | 你能看到 / 能做什么 |
| --- | --- |
| **概览** | 此刻在线人数、今日访问/访客/登录/新登记、24 小时流量柱状图、热门页面、**可疑访问**（当天请求数或错误数异常的 IP，一键封禁）、最近事件流水 |
| **实时访问** | 每 3 秒刷新一次的请求流水：时间、IP、身份、方法、路径、状态码、耗时、来源、设备。可暂停、可只看错误、每行都能封 IP |
| **访客档案** | 谁登记了、谁的在线点还亮着、最后出现时间、登录次数、发了多少内容、用过的 IP |
| **登录记录** | 所有登记和后台登录（含**密码输错**的记录） |
| **内容管理** | 回忆条目：置顶 / 隐藏 / 删除 / 查看；评论：隐藏 / 删除 |
| **导入回忆** | 见下一节 |
| **密码管控** | 见下面「密码管控」 |
| **站点设置** | **学校名称 / 站点全称 / 英文名**（见下）、公告、敏感词、是否允许新登记、首帖是否先审、**站长联系方式**、封禁名单、导出 CSV、清空访问日志 |

#### 改站名：学校名称 / 站点全称 / 英文名

后台 **站点设置** 最上面有三栏，改完点「保存设置」，**登录页大标题、顶栏、印章、页脚、浏览器标签页会一起变**，下面还有一块「效果预览」，边打字边变，不用先保存再看：

| 栏位 | 显示在哪 | 默认 |
| --- | --- | --- |
| **学校名称** | 登录页大标题（下面自动接「回忆录」）、顶栏印章、页脚印章 | `廊坊一中` |
| **站点全称** | 浏览器标签页、页脚那行「… · 由校友共同守护」 | `廊坊一中回忆录` |
| **英文名** | 登录页左侧大标题上方那行小字 | `LANGFANG NO.1 MIDDLE SCHOOL` |

三个小规矩：

- **站点全称留空** → 自动用「学校名称 + 回忆录」，所以只改学校名称也能全站统一。
- 改学校名称时，如果站点全称还是自动生成的那个（或空着），会**跟着一起改**；你自己填过一个不一样的全称就不再被覆盖。
- 英文名**清空就不显示**那一行（改成别的学校时记得改或清掉，免得还挂着旧校名）。

另有一个独立页面 **监控中心**（顶栏「监控中心 ↗」或 `/monitor`），把「看人」和「看文件」放在同一页：

| 区域 | 内容 |
| --- | --- |
| **统计条** | 此刻在线、登录用户在线、未发布的文档、今日上传、今日文档、命中敏感词、今日登录失败、今日被拦截、累计占用空间 |
| **此刻在线的人** | 近 5 分钟有访问的人：身份、IP、手机/电脑、点了多少次、最后去了哪些页面；可**踢下线**、**封禁此 IP** |
| **刚刚发生的事** | 登录/登录失败/登记/上传文档/发布文档/发帖/被拦/被锁/站长操作，按时间倒序，5 秒自动刷新 |
| **文件监控** | 所有上传记录（校友传的文档 + 站长导入的）：文件名、谁传的、IP、大小、解析出几条、状态、时间；点「看内容」能看到**解析后的每一条 + 原文**，命中的敏感词会高亮；可直接「下载原文件 / 删除」 |

「看内容」对小文件现场重新解析出前 50 条；已经解析好还没发布的文档直接读解析结果，不用再等；
超过 8MB 的文件只展示上传时的抽样开头，要看全文请下载原文件。删除是**连带**的：记录、原文件、
以及从这份文档发到墙上的回忆会一起删掉。

#### 密码管控（只有站长能进）

| 区域 | 作用 |
| --- | --- |
| **账号总览** | 登记账号数、已设密码 / 没设密码、密码偏短、已锁定、待改密、有输错的、已停用，一眼看全 |
| **账号列表** | 搜级别/班级/姓名/IP，按「没密码 / 已锁定 / 待改密 / 密码太短 / 有输错」筛；每个账号能：**重置密码**（留空自动生成 8 位临时密码，只显示一次）、**锁定/解锁**、**要求改密**、**踢下线**、**停用/恢复** |
| **密码策略** | 最短位数、连续输错几次自动锁定、锁多少分钟、重置后是否强制改密、是否允许校友自助改密码 |
| **密码日志** | 谁在什么时候被重置、自己改密、输错、被锁定/解锁，都留痕（也可导出 CSV） |
| **你的后台密码** | 在这里改站长自己的后台密码（哈希存库）；也能一键恢复成 `.env` 里那个 |

> 后台密码连续输错 8 次（15 分钟内）会被临时挡住，防止有人硬猜。
> 站长登录状态 12 小时过期；校友登录状态 30 天。
> 改了某个校友的密码 / 锁定 / 停用，对方所有设备上的登录会立刻失效。

#### 站长联系方式（登录页上的「有事找站长」）

登录页底部有一行「忘记密码 / 有事找站长」，点开就是一张小卡片：微信、QQ、邮箱、电话、
补充说明，每项后面带「复制」按钮，邮箱和电话可以直接点开。位置在后台 **站点设置** 最下面：

| 字段 | 说明 |
| --- | --- |
| 微信 / QQ | 最常用。建议填一个你自己看得住的号 |
| 邮箱 / 电话 | 选填；手机上点一下就能发邮件 / 拨号 |
| 补充说明 | 例如「加微信请注明几几级姓名，不然不加」 |
| 在登录页展示这些联系方式 | 总开关。关掉后登录页整块入口消失 |

两个细节：**微信 / QQ / 邮箱 / 电话 至少要填一项**才会显示，只填备注不会露出空壳入口；
联系方式是公开给所有访客的（不登录也能看到），所以建议填个专用的号，别填私人主号。

## 四、导入金山文档里的共享文档

金山文档的共享链接**需要登录才能看**，服务器没法直接抓 —— 所以提供了三条路，
任选其一，都能落到同一个「预览 → 逐条校对 → 确认导入」的流程里。

### 方法 A（最稳）：下载成 Word 再上传

1. 在金山文档里打开那篇共享文档 →「另存为 / 下载」→ 选 **.docx**
2. 后台 →「导入回忆」→ 把文件拖进虚线框
3. 系统自动识别「98级3班 张三」这样的署名行分段，逐条列出来
4. 每条都能改级别、班、姓名、标题、正文，确认无误 →「确认导入」

支持 `.docx` `.txt` `.md` `.html` `.csv`，**后台导入单文件最大 2.5GB**（`MAX_IMPORT_UPLOAD_MB` 可调；
校友自己传文档走的是另一个上限 `MAX_UPLOAD_MB`，默认 500MB）。
`.doc` 和 `.pdf` 请先在金山里另存为 `.docx`（老格式和 PDF 没有可靠的中文段落结构，硬解析会乱）。

> `.docx` 用流式解压（`yauzl` 边解边抽 `word/document.xml` 里的文字），不把整份文件读进内存，
> 所以 2.5GB 的 Word 也能传；但第一次解析会读很久（几十秒到几分钟），页面上的进度条会先跑完上传、再显示"正在解析"。
> 更稳的做法是大合集**导出成 `.txt` 再传**（流式逐行读，最快）。
> 上传后文件先停在 `uploads/docs/`，**导入完就删**，请确认服务器磁盘至少留出上传大小的两三倍 ——
> 2.5GB 的文件意味着临时目录得有 3GB 以上空余，否则会传一半失败。
> Nginx 那边 `client_max_body_size` 要 >= 2600m（部署文件里已给到），否则会先被 413 挡掉。

### 方法 A+（整篇文档模式）：一份 Word 直接当一条回忆，照片原样保留

如果整篇《回忆录》本来就写在一个 Word 里（图文混排、有标题和表格），**不要**按署名拆成一条条 ——
拆出来的那些会丢掉照片。请用「**导入 → 整篇文档**」这个标签：

1. 标题 / 级别 / 署名可以留空：留空就用文件名当标题，级别从文件名里的年份自动认，署名默认「XX级合集」
2. 把 `.docx` 拖进去（或点一下选文件）
3. 服务器把它转成一条回忆：段落、标题（Heading）、表格、加粗/斜体/下划线都保留，
   **文档里的照片一张张抽出来、插回原来的位置**，并生成一张封面图
4. 传完直接出现在回忆墙上（墙上会标「整篇文档」+ 封面 + 照片张数），点「翻整篇」看全文，
   照片点一下能放大，也能照样点赞、评论

存的量级参考：一份 424MB、225 张照片的 Word，转完照片总共 443MB 落在 `uploads/posts/<回忆id>/`，
正文 HTML 也在这个目录里（`body.html`），`data/db.json` 里只存纯文本摘要，不会把数据库撑大。
所以请留意磁盘：**照片是按原尺寸存的**，一份文档可能占几百 MB，删这条回忆时会连照片一起删掉。

`.txt` / `.md` / `.html` / `.csv` 也能用整篇模式，但没有照片，就是整篇文字发一条。

#### 文档里的超链接

三种写法都会变成**能点的链接**，点击在新标签页打开：

| Word 里的写法 | 转成 |
| --- | --- |
| 插入 → 超链接（`w:hyperlink`） | `<a href>` 包住那串文字 |
| WPS / 在线文档的「附件 / 共享链接」图标（HYPERLINK 域代码里放一张小图标） | 图标本身变成可点的链接 |
| 正文里直接写出来的网址（`https://…`、`www.…`） | 自动识别成链接 |

出于安全，只放行 `http(s)` 和 `mailto`，`javascript:`、`file:`、指向本机路径的链接会被丢掉（只留文字）。
链接是在**生成 HTML 时**烘焙进去的，所以文档改了要重新导入一次才会更新。

自检：`npm run test:docx` 会现场造一份带超链接 / 域代码 / 裸网址 / `javascript:` 的 .docx，
转换后逐条断言（6 项，不需要启动服务器）。

> 相关上限（`.env` 可改）：`MAX_DOC_IMAGES_MB`（默认 4096，一篇里照片总量上限）、
> `MAX_DOC_XML_MB`（默认 192，Word 内部 `document.xml` 上限）、`MAX_DOC_HTML_CHARS`（默认 6000000，正文 HTML 上限）。
> 超了不会崩，只是后面的图和文字不再载入，页面上会提示「文档太长，尾部内容没载入」。

### 方法 B：共享链接是「公开分享」时直接抓

后台 → 导入 → 「金山链接」标签 → 粘贴链接 →「尝试抓取」。

要点：链接必须是 **任何人都能看** 的那种（金山里设成「互联网获得链接的人可查看」）。
如果是「仅指定人可看」，抓到的只会是登录页，程序会明确告诉你失败原因。
提示「需要登录」时不要反复试，直接用方法 A。

### 方法 C：直接粘贴文字

后台 → 导入 → 「粘贴文本」→ 把内容从金山里全选复制过来 → 「解析」。
适合几十条、结构不规整的稿子。

### 导入时最好让文档长这样

```
1998级3班 张三
记得那年冬天特别冷，教室的暖气片半夜不热……

1999级1班 李四
高三那年我们一起翻墙出去吃烧烤，被教导主任抓住了。

2000级 王五
我只记得操场边那排杨树，还有每天早上的广播体操。
```

规矩很简单：

- **一行署名**开头（`1998级3班 张三`、`98届 李四`、`2001级 王五` 都认），后面直到下一个署名行，都算这个人的回忆
- 一行里没有署名 → 归到上一个人名下续写；开头没有署名的段落会被跳过
- 也认 CSV / Tab 分隔表格，表头里有「姓名」列即可（列名可以写 级别/届别/年份、班级、姓名、标题、正文）

## 五、部署到云服务器

假设你已经买了一台 Linux 云主机（阿里云/腾讯云都行，**建议 2 核 2G、系统盘 80G 起**），
域名（可选）解析到了这台机器。

> **腾讯云轻量应用服务器用户**：直接看 [`deploy/腾讯云轻量部署.md`](deploy/腾讯云轻量部署.md)，
> 里面有买什么配置、防火墙怎么放行、**域名备案**要多久、以及一条命令装完的脚本
> `deploy/lighthouse-install.sh`。下面三种方式和它不冲突，任选一种即可。

### 方式零：一条命令（腾讯云轻量 / 任意 Ubuntu·Debian·CentOS）

```bash
# 代码传上去之后（见文档第 2 步）
cd /opt/langfang-memoir
sudo DOMAIN=memoir.example.com bash deploy/lighthouse-install.sh
```

脚本会装 Node 20、建专用用户、`npm install`、生成随机 `.env`、装 systemd 服务、装 nginx 反代（含 2.5GB 上传配置），
最后自检并打印后台密码。可以重复执行。

### 方式一：Docker（推荐，最省心）

```bash
# 1. 装 Docker（已装可跳过）
curl -fsSL https://get.docker.com | sh

# 2. 把代码上传到服务器（在自己电脑上执行）
scp -r langfang-memoir root@你的服务器IP:/root/

# 3. 进目录，改配置
cd /root/langfang-memoir
cp .env.example .env
nano .env       # 至少改 SESSION_SECRET 和 ADMIN_PASSWORD

# 4. 起服务
docker compose -f deploy/docker-compose.yml up -d --build
```

打开 `http://服务器IP` 就能访问了。数据在 Docker 卷里，`docker compose down` 再 `up` 不会丢。

> 想换端口/thumbs：改 `deploy/docker-compose.yml` 里 nginx 的 `ports`。
> 想上 HTTPS：把域名解析过来，装 certbot（命令见 `deploy/nginx.conf` 末尾注释）。

### 方式二：systemd 裸跑（不用 Docker）

```bash
# 1. 装 Node 20
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 2. 上传代码 + 装依赖
sudo mkdir -p /var/www/langfang-memoir
sudo chown -R $USER:$USER /var/www/langfang-memoir
# （用 scp / git / 宝塔面板把文件传进去）
cd /var/www/langfang-memoir
npm install --omit=dev

# 3. 配 .env
cp .env.example .env && nano .env

# 4. 装成系统服务
sudo cp deploy/langfang-memoir.service /etc/systemd/system/
sudo nano /etc/systemd/system/langfang-memoir.service   # 改 User 和路径
sudo useradd -r -s /sbin/nologin memoir
sudo chown -R memoir:memoir /var/www/langfang-memoir
sudo systemctl daemon-reload
sudo systemctl enable --now langfang-memoir

# 5. 前面挂 nginx 反代（可选但建议）
sudo apt install -y nginx
sudo cp deploy/nginx.conf /etc/nginx/conf.d/memoir.conf
sudo nano /etc/nginx/conf.d/memoir.conf    # server_name 改域名、upstream 改 127.0.0.1:3000
sudo nginx -t && sudo systemctl reload nginx
```

### 方式三：宝塔面板

1. 软件商店装 **Node.js 版本管理器**，装 20.x
2. 上传 `langfang-memoir` 到 `/www/wwwroot/`
3. 「网站」→ 添加站点 → Node 项目 → 启动文件填 `server/index.js`，端口 3000
4. 终端进目录 `npm install --omit=dev`，然后「启动」
5. 记得在「安全」里放行 80/443，别把 3000 直接暴露出去

### 上线前必改的三处

| 位置 | 改成什么 |
| --- | --- |
| `.env` 的 `SESSION_SECRET` | 一长串随机字符（改了所有人要重新登记，所以上线前就定好） |
| `.env` 的 `ADMIN_PASSWORD` | 只有你知道的强密码 |
| `.env` 的 `SITE_URL` | `https://你的域名`（用 https 才会让 Cookie 带 Secure） |

另外：用了 nginx / Docker 反代，**一定**要设 `TRUST_PROXY=1`，否则后台看到的全是 `127.0.0.1`，封禁也就封不住人。

### 备份

```bash
# 手动备份一次
npm run backup

# 每天凌晨 3 点自动备份，保留 30 份
crontab -e
0 3 * * * cd /var/www/langfang-memoir && /usr/bin/node scripts/backup.js
```

备份是 `backups/db-日期-时间.json.gz`。恢复：解压后覆盖 `data/db.json`，重启服务。
图片在 `uploads/`，一起拷走；照片多的话建议用 `rsync` 定期同步到别的机器。

## 六、配置项（`.env`）

复制 `.env.example` 为 `.env` 再改。全部可空，留空就是默认值。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | 监听端口 |
| `SITE_URL` | 空 | 站点对外地址，如 `https://memoir.example.com`。https 时 Cookie 会加 Secure |
| `SESSION_SECRET` | 自动生成 | Cookie 签名密钥。**上线前手动定死** |
| `ADMIN_PASSWORD` | 自动生成 | 后台密码。不填则生成随机密码存到 `data/.admin-password` 并打印 |
| `TRUST_PROXY` | `0` | 置 `1` 时才信任 `X-Forwarded-For`（反代后面必须开） |
| `DATA_DIR` | `data` | 数据目录 |
| `UPLOAD_DIR` | `uploads` | 图片目录 |
| `REVIEW_FIRST_POST` | `0` | `1` = 每个人发第一条回忆先隐藏待审 |
| `MAX_POST_CHARS` | `8000` | 单条回忆正文上限 |
| `MAX_UPLOAD_MB` | `500` | 校友自己传文档的上限（MB） |
| `MAX_IMPORT_UPLOAD_MB` | `2560` | 站长后台导入回忆的上限（MB，2.5GB） |
| `DOC_DAILY_LIMIT` | `10` | 每个校友每天最多传几份文档 |
| `MAX_IMAGE_MB` | `8` | 单张配图上限（MB），每条最多 6 张 |
| `MAX_DOC_IMAGES_MB` | `4096` | 「整篇文档」模式下，一篇里的照片总量上限（MB） |
| `MAX_DOC_XML_MB` | `192` | Word 内部 `document.xml` 上限（MB），正常文档几 MB |
| `MAX_DOC_HTML_CHARS` | `6000000` | 整篇转出来的正文 HTML 上限（字符），超了尾部截断 |

## 七、安全上做了什么

- 校友密码用 **scrypt + 随机盐** 存哈希（不存明文，数据库被拷走也看不出密码），比对走 `timingSafeEqual`
- 后台密码默认只在 `.env` / `data/.admin-password` 里，界面上改过的存哈希；两者都不回显
- 会话里绑定密码版本号：改了密码、被重置、被踢、被停用，旧 Cookie 立即失效
- 连续输错可自动锁定（默认 8 次锁 30 分钟，可调）；失败次数按账号累计，不受换 IP 影响
- 登录态是 `HMAC-SHA256` 签名的 Cookie，`HttpOnly` + `SameSite=Lax`，https 下自动加 `Secure`；会话表在服务端，可随时踢下线
- 全站 CSP：脚本只允许同源（`script-src 'self'`），因为所有前端代码都是自己写的；`X-Frame-Options` 防点击劫持
- 正文过滤 `<script>` / `<iframe>`，前端一律 `textContent` / `esc()` 输出，不拼 HTML
- 敏感词可在后台配；命中就不让发
- 每个写接口都有独立限流（发帖 1 小时 12 条、评论 10 分钟 30 条、点赞 1 分钟 60 次、登记/登录 10 分钟 12/30 次、后台登录 15 分钟 8 次……）
- 访客可被一键封禁，封禁后所有请求返回 403 并记事件
- 上传只收图片扩展名 + 白名单路径校验，防止传 `.html` 或路径穿越

**已知局限（说清楚）：** 密码只证明「这台浏览器记得这个人」，并不核实「这个人真是张三个人」——
同年同班同名的人还是可能撞车（撞了会提示写班级）。真怕冒充，就把敏感词、首帖审核打开，并勤看后台。
另外：密码默认允许 1 位，是为了让老同学好记；如果站里人多、你想严一点，去后台「密码管控 → 密码策略」把最短位数调到 6 位以上。

## 八、常见问题

**Q：部署到腾讯云之后，别人用普通浏览器能打开吗？**
能。两个前提：控制台**防火墙放行 80/443**，以及用域名访问时**域名必须完成 ICP 备案**（国内地域，1～3 周）。
备案没下来之前可以先让大家用 `http://公网IP:3000` 访问，功能一样。完整步骤见
[`deploy/腾讯云轻量部署.md`](deploy/腾讯云轻量部署.md)。

**Q：`npm install` 报错 / 很慢？**
换国内镜像：`npm config set registry https://registry.npmmirror.com`。

**Q：忘记后台密码了？**
看 `.env` 里的 `ADMIN_PASSWORD`；没设过就看 `data/.admin-password` 文件。都丢了就删掉该文件重启，会生成新的。
如果你在后台「密码管控 → 你的后台密码」里改过、又把 `.env` 忘了，就直接删 `data/db.json` 里的
`settings.adminPwd` 这一段（先备份），或用 `data/.admin-password` 里的原始密码试。

**Q：校友忘了他的密码？**
后台 → 密码管控 → 找到这个人 → 「重置」。留空会自动生成 8 位临时密码，**只显示这一次**，复制给他；
他登录后会被要求立刻改成自己的密码。

**Q：为什么浏览器没提示保存密码？**
① 用的是无痕窗口；② 浏览器设置里「自动填充 → 密码」被关了；③ 之前在这个域名点过「永不保存」，
去浏览器设置里删掉那条记录；④ 手机上用的是 App 内置浏览器（微信/QQ），换成系统浏览器。
手动填一次并成功登录，浏览器通常就会记住。

**Q：能禁止别人自己改密码吗？**
能：后台 → 密码管控 → 密码策略 → 关掉「允许校友自助改密码」。关掉后首页「账号」页会提示找站长。

**Q：端口 3000 被占用？**
`.env` 里写 `PORT=3100`，或关掉占用它的程序。

**Q：导入 Word 以后全是乱的？**
文档里没有「级别 班 姓名」署名行时，程序只能靠空行硬分段。稳妥做法：在金山里把每个人的那段前面加一行署名，再导出。

**Q：多条回忆里带了同样的图片？**
每条回忆的图片是独立的，导入只带文字，图片请在站内单独上传。

**Q：能改站名吗？**
能。后台 → **站点设置** → 「学校名称 / 站点全称 / 英文名」，保存后登录页大标题、顶栏、印章、页脚、浏览器标签页全都会变，
旁边还有实时预览。站点全称留空就自动用「学校名称 + 回忆录」。详见上面「改站名」那张表。

**Q：校友传了文档，去哪了？**
校友点「把 N 条全部发到墙上」之后就直接上墙了（不等审核）。你在后台 **监控中心 → 文件监控** 里能看到
这每一份上传：谁传的、IP、多大、解析出几条、有没有敏感词；点「看内容」能看到解析出的每一条和原文。
觉得不合适点「删除」，这条记录、原文件和它发上墙的那些回忆会一起没掉。想删单条回忆或评论，去「内容管理」。

**Q：传大文件失败？**
按顺序查：① Nginx 的 `client_max_body_size` 是否 >= 你要传的上限（部署文件里是 `2600m`，老服务器要手动同步）；
② 应用侧两个口子够不够：校友传文档 `MAX_UPLOAD_MB`（默认 500）、站长后台导入 `MAX_IMPORT_UPLOAD_MB`（默认 2560 = 2.5GB）；
③ 服务器磁盘 / 临时目录还有空间（`uploads/docs/` 要能放下整个文件，2.5GB 就别只留 1GB）；
④ 如果是很大的 `.docx`，解析要跑一阵——导出成 `.txt` 再传更稳（文本是流式逐行读，最快）。
超限时页面会明确告诉你上限是多少，上传过程中还有进度条和"正在解析"，不会传一半没反应。

**Q：怎么知道有没有人想搞破坏？**
顶栏「监控中心」，一页看完：谁在线、都在点什么、有没有人被拦（403）、登录失败多少次、谁传了什么文档。
看到不对的 IP 直接「封禁此 IP」，看到可疑内容直接「删除」。

**Q：手机上能用吗？**
能，页面做了响应式（900px / 560px 两个断点）。后台在手机上也能开，就是表格要横着滑。
